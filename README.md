# News_Agent
This repo demonstrates how to build a multi-agent summarization system using LangGraph for processing news articles. It showcases a workflow where agents collaborate to fetch, analyze, and summarize news content into concise TL;DRs. The notebook integrates LangChain, OpenAI models, and external tools to simulate agent-based language understanding. It’s ideal for exploring real-world applications of autonomous agents in news analysis, content generation, and summarization pipelines.

Note: Make sure to configure your OpenAI API key and install required libraries before running the notebook.
